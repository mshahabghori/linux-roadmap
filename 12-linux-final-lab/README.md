# Day 12 — Linux Final Lab

**Status:** Completed  
**Purpose:** Consolidate Linux command-line skills through an independent practical challenge.

## Skills Practiced

### 1. Filesystem Management
- Navigate the filesystem
- Create directories and files
- Copy, move, and rename files
- Delete test files safely

### 2. Users, Groups, and Permissions
- Create and manage users
- Create and manage groups
- Modify file permissions with `chmod`
- Change ownership with `chown`

### 3. Packages and Text Processing
- Install packages using APT
- Search file contents with `grep`
- Combine commands using pipes
- Redirect and append command output

### 4. Environment and Bash
- Read environment variables
- Create and export variables
- Use Bash expansions and wildcards
- Understand output redirection with `>` and `>>`

### 5. SSH, File Transfers, and Services
- Connect to a Linux system using SSH
- Transfer files using SCP
- Start, stop, and inspect services
- Inspect relevant system and service logs

## Completion Criteria

The final challenge was completed independently from a fresh terminal, without following a tutorial.

## Safety Notes
- Use test files and test accounts for practice.
- Avoid modifying system-critical files.
- Use `sudo` only when necessary.
- Never expose private SSH keys.
