# User Management Lab

Hands-on practice with Linux users, groups, sudo, su, and account files.

## Commands Practiced

whoami
id
groups
sudo
su
adduser
addgroup
usermod
cat /etc/passwd
cat /etc/group
sudo cat /etc/shadow

## Tasks Completed

- Checked user and group information
- Practiced sudo and root access
- Created a test user
- Created a test group
- Added the test user to the group
- Verified group membership
- Inspected Linux account files
- Tested access restrictions

## Safety

Actual `/etc/shadow` contents and password hashes are not stored in this repository.
