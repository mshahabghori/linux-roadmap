# 05 — Permissions + Package Management

Hands-on Linux practice covering file permissions, ownership, and APT package management.

## Topics Covered

- `ls -l`
- Owner, group, others
- Read, write, execute permissions
- Numeric permissions
- `chmod`
- `chown`
- `chgrp`
- APT package management
- `apt update`
- `apt install`
- `apt remove`
- `apt upgrade`
- `apt autoremove`

## Cybersecurity Relevance

- File permissions provide access control.
- Ownership determines who controls files.
- Groups allow controlled access between users.
- Incorrect permissions can expose sensitive files or enable privilege escalation.
- Keeping packages updated helps reduce exposure to known vulnerabilities.
