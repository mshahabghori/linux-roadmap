# Package Management Lab

[← Day 5](../../README.md) · [← Roadmap](../../../README.md)

Hands-on practice with APT package management on Ubuntu.

## Commands Practiced

```bash
sudo apt update
sudo apt install <package>
sudo apt remove <package>
sudo apt upgrade
sudo apt autoremove
```

## Concepts Practiced

- Updating package lists
- Installing software
- Removing software
- Upgrading installed packages
- Removing unnecessary dependencies

## Security Relevance

Package management is important for maintaining a secure Linux system. Regular updates can provide security patches and reduce exposure to vulnerable software.
