# Day 7 Lab — Pipes and Redirection

## Objectives
- Practise input, output, and error redirection.
- Understand pipes and command chaining.
- Filter and count log entries.
- Capture errors and save command output.

## Commands Practised
- `>` and `>>`
- `<`
- `2>`
- `2>&1`
- `|`
- `tee`
- `grep`
- `wc -l`

## Lab Files
- `output.txt` — practice output and sample login messages
- `errors.txt` — redirected error messages
- `combined.txt` — combined standard output and standard error
- `failed-logins.txt` — filtered failed-login messages
- `all-output.txt` — output and errors captured through a pipe

## Outcome
Practised Linux I/O redirection, pipes, text filtering, and basic log investigation.
